# KEMET — Архитектура вечности

Интерактивный атлас древней инженерии Египта на русском языке.

**Открыть приложение:** https://evgk724.github.io/kemet-atlas/

![QR-код приложения](qr.png)

## Внутри

- Пирамида Хеопса, Осирион, Ломаная пирамида, пирамида Джосера, Серапеум Саккары, Незаконченный обелиск Асуана.
- По три авторские учебные схемы: объём, разрез, план.
- Интерактивные точки с пояснениями, увеличение и разворачивание чертежей.
- Подтверждённые сведения и открытые вопросы, инженерные пояснения, линия времени и вопросы для повторения.
- Библиотека археологических и научных источников внутри приложения; структурированные материалы в `sources.json`.
- QR-код и копирование ссылки в самом приложении.
- Оригинальная иконка для шапки, вкладки браузера и домашнего экрана iPhone/iPad.
- Выбор размера текста: крупный (22,5 px), очень крупный (24,75 px) и максимальный (27 px для основного текста). По умолчанию включён очень крупный. Настройка сохраняется локально в браузере.
- Адаптация под iPhone Pro Max и iPad; на узких экранах подписи чертежей вынесены в читаемый текст под рисунком.

## Использование

Приложение представляет собой один самодостаточный `index.html`: CSS, JavaScript, векторные схемы и QR-код встроены. Внешних библиотек, шрифтов, аналитики и API нет. Скачанный HTML-файл открывается в браузере без интернета; переход к внешним источникам требует подключения.

Для локального просмотра можно открыть `index.html` непосредственно или запустить `python3 -m http.server 8000` в каталоге проекта.

GitHub Pages публикует ветку `main`, корневой каталог. Файл `.nojekyll` отключает обработку Jekyll.

## Научные границы

Схемы предназначены для объяснения и не заменяют археологические обмерные чертежи. Геометрия отдельных внутренних элементов упрощена. Реконструированные части и неопределённость оговариваются на странице соответствующего объекта. Источники проверены 9 октября 2026 года.

Big Void (2017) и северный коридор (исследование 2023) показаны отдельно. Современное затопление Осириона не выдаётся за древний водный режим. Масса Незаконченного обелиска обозначает расчёт для завершённого объекта; его не перевозили и не устанавливали.

## Файлы

`index.html` — приложение. `qr.png` — QR-код для экрана. `qr.svg` — векторная версия для печати. `sources.json` — фактическая основа и библиография. `assets/` — иконки приложения разных размеров. `site.webmanifest` — описание приложения для добавления на домашний экран. Авторские схемы и значок шапки содержатся внутри HTML.


## Автообновление и крупный текст

- Онлайн-версия по умолчанию проверяет `version.json` при открытии, возвращении на страницу, восстановлении соединения и раз в минуту, пока страница видима. В фоне iOS может приостанавливать вкладку; проверка возобновляется при возвращении.
- В «Об атласе → Обновления приложения» есть переключатель автообновления, ручная проверка и кнопка установки найденной версии.
- Автоматическое применение ждёт завершения активного повторения, закрытия диалогов/полноэкранного чертежа и паузы в действиях. «Позже» откладывает обновление на пять минут. При ошибке сохранения прогресса автоматическое и ручное применение блокируются, чтобы не потерять текущие результаты.
- Перед переходом проверяется HTML конкретной новой версии по тому же URL. Неполная публикация или ошибка сети не вызывают переход. Неудачная установка одной версии не запускает бесконечную перезагрузку.
- Сохраняются прежние ключи истории и настроек. Выбранные объект/вид, фильтры, размер текста и положение чтения передаются новой странице. Приложения используют отдельные ключи хранения на общем домене GitHub Pages.
- Автообновление относится к опубликованным версиям приложения. Сохранённый файл `file://` остаётся автономной копией; в нём есть ссылка на онлайн-версию.
- Три размера основного текста: 22,5 / 24,75 / 27 CSS px. По умолчанию выбран средний; сохранённый выбор пользователя имеет приоритет. Насыщенность основного текста увеличена до 600, заголовков и большинства элементов управления — до 700–750.

Уже открытая старая версия без модуля обновлений требует однократного обычного обновления страницы. Последующие опубликованные версии будут обнаруживаться автоматически. Ссылки приложения и QR-коды не изменились.

Сборка `python3 scripts/build.py` сама формирует идентификатор из содержимого страницы и ресурсов и записывает `version.json`; вручную менять номер версии не требуется. В коммит нужно включать всю обновлённую сборку вместе с манифестом версии.

Браузерные регрессионные тесты обновления (требуется установленный Playwright с браузерами):

```sh
node tests/updater.cjs webkit
node tests/updater.cjs chromium
```

Проверяемые сценарии: новая версия, сохранение прогресса и настроек, активная карточка, отключение обновлений, ручная установка, сетевой сбой, частично опубликованная версия, запрет хранения, несохранённый прогресс, устаревший корневой URL, защита от цикла перезагрузок и «Позже» во время медленной загрузки.


## Исходники KEMET

Исходники теперь находятся в `src`, воспроизводимая сборка — в `scripts/build.py`. GitHub Pages по-прежнему публикует корень ветки `main`. `KEMET.html` — самостоятельная офлайн-копия со встроенными схемами и иконками.

```sh
python3 scripts/build.py
python3 -m http.server 8769 --bind 127.0.0.1
```


Проверка этого обновления: WebKit — 84 сочетания приложения, размера экрана и шрифта; Chromium — ещё 36. Профили: 440×956 и 956×440 (iPhone 18 Pro Max), 820×1180 и 1180×820 (iPad Air 11″), 1024×1366 и 1366×1024 (iPad Air 13″), а также узкий экран 320×740. Во всех четырёх приложениях дополнительно проверены все объекты и все ответы при максимальном тексте на ширине 320 px. Горизонтального переполнения и обрезанных элементов в этих сценариях не обнаружено. Проверка выполнена в браузерных профилях, не на физических устройствах.


## Масса, размеры и инженерные вопросы — 10 октября 2026

Файл `engineering.json` хранит числовые карточки, источники, вопросы и краткие ответы для повторения. `src/engineering.js` и `src/engineering.css` выводят их в атласе; сборка встраивает всё в HTML для чтения без интернета. Ключевые числа набраны примерно в полтора раза крупнее подписей и жирнее; размер меняется вместе с выбранным размером текста.

- Для каждого числа названа конкретная часть памятника и указан тип сведений: обмер, историческая оценка или редакционный расчёт. Масса короба отделена от крышки; установленные блоки — от оставшихся в карьере.
- Четыре фильма Proto Civilization связаны прямыми YouTube-ссылками. Комментарии подготовлены по доступным расшифровкам; независимых измерений видеокадров не проводилось. Полные расшифровки и чужие кадры в репозитории не публикуются.
- Разобраны ограничения круглых долеритовых ударников, эксперимент Marčiš & Fraštia 2023, абразивная обработка, параллельные следы, различие шероховатости и геометрии, реконструкции подъёма и паспортные возможности современных кранов.
- Открытый ответ в блоке числового повторения также приостанавливает автоматическую перезагрузку.

Проверка новой версии: 540 состояний с раскрытыми пояснениями в WebKit и Chromium, три размера текста, портретные и альбомные профили телефона и двух размеров iPad Air, включая узкий экран 320 px. Переполнений и ошибок JavaScript не обнаружено. Новые схемы просмотрены визуально. Автообновление проверено с сохранением выбранного объекта, шрифта и реального прогресса; новые числовые ответы защищены от перезагрузки. Это браузерная эмуляция, не испытание на физических iPhone/iPad.
